# dag-visualizer

Angular 21 workspace for **ngx-dag-visualizer**: a from-scratch DAG visualizer (no third-party graph libraries).

- Library: `projects/ngx-dag-visualizer`
- Demo: `projects/demo`

```bash
npm start
```

Opens the ETL pipeline demo. `npm run test` runs layout/graph unit tests. `npm run build:lib` builds the publishable package.
